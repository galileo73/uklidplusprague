# Post-Launch Checklist: First 30 Days

**Project:** UKLID PLUS PRAHA
**Purpose:** Ensure successful launch, monitor performance, optimize conversions
**Timeline:** 30 days after deployment

---

## Launch Day Checklist

### Pre-Launch (2 hours before)

#### Technical Verification
- [ ] Run final build: `npm run build`
- [ ] Preview locally: `npm run preview`
- [ ] Test all pages load
- [ ] Test all WhatsApp links
- [ ] Test contact form submission
- [ ] Test on mobile device
- [ ] Check console for errors (F12)
- [ ] Verify responsive breakpoints

#### Content Verification
- [ ] Phone number correct
- [ ] WhatsApp number correct
- [ ] All images loading
- [ ] Logo displaying
- [ ] Social links working
- [ ] Email address correct

#### SEO Verification
- [ ] robots.txt accessible at `/robots.txt`
- [ ] sitemap.xml accessible at `/sitemap.xml`
- [ ] Meta title displays
- [ ] Meta description displays
- [ ] Favicon displays

### Launch (Deployment)

#### Deploy to Production
- [ ] Push to main branch
- [ ] Wait for Netlify build
- [ ] Verify build succeeds
- [ ] Check live site loads

#### Immediate Post-Launch
- [ ] Clear browser cache
- [ ] Test live site on desktop
- [ ] Test live site on mobile
- [ ] Test WhatsApp links on phone
- [ ] Submit test contact form
- [ ] Verify form submission received

#### DNS & SSL
- [ ] Verify domain resolves
- [ ] Check HTTPS certificate
- [ ] Test www redirect (if configured)
- [ ] Verify all internal links use HTTPS

## Common Issues & Solutions

### Low Traffic (Week 1-2)
**Causes:**
- Not yet indexed
- No backlinks
- No social presence

**Solutions:**
- Share on social media
- Submit to directories
- Request indexing
- Build backlinks

### High Bounce Rate
**Causes:**
- Slow page load
- Poor mobile experience
- Wrong audience

**Solutions:**
- Optimize images
- Check mobile experience
- Review traffic sources
- Improve content

### Low Conversion Rate
**Causes:**
- Unclear CTAs
- Wrong audience
- Trust issues

**Solutions:**
- Improve WhatsApp visibility
- Add trust signals
- Add testimonials
- Simplify contact process

### No Indexing
**Causes:**
- robots.txt blocking
- No sitemap
- New domain

**Solutions:**
- Check robots.txt
- Submit sitemap
- Build backlinks
- Be patient (can take 4 weeks)

## Emergency Contacts

### Critical Issues
- **Site Down:** Check Netlify status, redeploy
- **Domain Issues:** Check DNS settings, contact registrar
- **SSL Problems:** Wait for propagation, contact Netlify support
- **Form Not Working:** Check Netlify forms, test notifications

### Response Times
- Site down: Investigate immediately
- Major bug: Fix within 24 hours
- Minor issue: Fix within 1 week
- Enhancement: Schedule for next sprint
