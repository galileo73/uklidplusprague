## 🖼️ Image Guidelines

### Gallery Images (Before/After)
| Specification | Requirement |
|---------------|-------------|
| Minimum width | 1200px |
| Aspect ratio | 4:3 or 16:9 |
| File format | JPG or WebP |
| Max file size | 500KB |
| Style | European apartment aesthetics |
| Content | Real Prague properties |
| Lighting | Natural, bright |
| Quality | Professional or high-quality amateur |

### Photography Style
- ✅ Clean, well-lit spaces
- ✅ European apartment features
- ✅ Professional appearance
- ❌ Cluttered rooms
- ❌ Dark, grainy photos
- ❌ American suburban style

## Brand Voice Guidelines

### Tone
- Professional but approachable
- Trustworthy and reliable
- Expat-friendly (clear English)
- Service-oriented

### Key Messages
- "Premium cleaning for Prague's international community"
- "Trusted by expats since 2015"
- "Multilingual support: EN/CZ/RU/UA"
- "WhatsApp-first booking"

### Terms to Use
- ✅ Premium cleaning
- ✅ Professional
- ✅ Reliable
- ✅ Multilingual
- ✅ Expat-friendly
- ✅ Trusted

### Terms to Avoid
- ❌ Cheap
- ❌ Basic
- ❌ Budget
- ❌ Quick (implies low quality)

## Contact for Branding Assets

When preparing assets, ensure:
1. Logo has transparent background
2. Logo works on #050505 background
3. All images are optimized for web
4. File names follow naming convention (lowercase, hyphens)
5. Images are compressed but high quality
